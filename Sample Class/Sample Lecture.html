Reading HTML notes

This is an ordinary HTML page sitting in a class folder. The desktop treats it as a first-class document: Preview shows it with its own styling, Books paginates it into a book, and Read Aloud speaks it while highlighting each word.

How it gets here

Drag an HTML file onto any Finder window — or onto the desktop — and it is saved into that folder on disk, then appears in the sidebar straight away. You can also use File ▸ Import Files…, or ⌘I.

Anything you drop lives in the real folder, so it is still there after you close the browser.

Three ways to read it

Select the file and the toolbar offers Read, which opens the paged reader with contents and bookmarks, and a speaker button, which opens Read Aloud. Double-clicking opens Preview, where both buttons are also available.

Maths survives

Inline maths such as \(P(A \mid B) = P(A,B)/P(B)\) is typeset by the paged reader, so lecture notes keep their equations.
