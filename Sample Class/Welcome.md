# Welcome

This is a sample note, so a fresh clone has something to open. Delete the
**Sample Class** folder once you've added your own.

## Adding your notes

Make a folder per class next to this one and drop files in — `.html`, `.pdf`,
`.docx`, `.md`, `.txt`, `.epub` and more all work:

```
macOS_Class_Summaries/
  cs cm121/
    lecture-01.html
  math 170a/
    week1.pdf
```

Then **View ▸ Rescan Files** (⌘R), or relaunch `open-mac.command`.

## Reading

Select this file and press the blue **Read** button in the toolbar. You get pages
instead of a scrollbar, contents built from the headings, bookmarks, four themes
and text sizing. Your place is remembered.

Maths is typeset, so $e^{i\pi} + 1 = 0$ comes out properly, as does display maths:

$$ P(A \mid B) = \frac{P(A, B)}{P(B)} $$

## Keyboard

- ⌘K — Spotlight
- Space — Quick Look
- ⌘1 / ⌘2 / ⌘3 — icon, list, column views
- ← → — turn pages while reading
